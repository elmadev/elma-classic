1. Install https://emscripten.org/docs/getting_started/downloads.html
2. If Windows VSCode, run the Emscripten terminal by adding it to VS Code and spawning a new console:

settings.json
{
  "terminal.integrated.profiles.windows": {
    "Em Command Prompt": {
      "path": [
        "${env:windir}\\Sysnative\\cmd.exe",
        "${env:windir}\\System32\\cmd.exe"
      ],
      "args": [
        "/k",
        // update as appropriate if your IDE installation path
        // is different, or if using the standalone build tools
        "cd C:/Programs/emsdk && emcmdprompt.bat"
      ],
      "overrideName": true,
      "icon": "terminal-cmd"
    }
  }
}

3. If on Windows, make sure to cd back to main directory
4. Update emscripten.ini file path
On Linux, it would probably be 'emcc' but dunno
5. meson setup build-em --cross-file emscripten.ini
6. meson compile -C build-em
7. emrun build-em/output.html
